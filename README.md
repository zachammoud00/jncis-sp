# HPE / Juniper JNCIS-SP Knowledge Base & Labs

Welcome! This repository serves as my personal study guide and hands-on lab repository for the **JNCIS-SP (Juniper Networks Certified Specialist Service Provider)** certification.

## 🎯 Repository Purpose 

**Topic Breakdowns:** Detailed notes explaining key networking concepts in my own words, supported by custom topology diagrams.

**Hands-On EVE-NG Labs:** Lab walkthroughs, configuration files, and topology exports for practical implementation. 

--- 

## 🛠️ Lab Setup & Prerequisites

All labs in this repository are built and tested using **EVE-NG**. 

Each lab directory contains:

**Lab Overview & Objectives:** Brief explanation of what the lab tests.

**Topology & Configs:** network topology and initial/final device configurations.
